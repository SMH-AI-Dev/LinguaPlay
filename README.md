# 🌍 LinguaPlay

### یادگیری زبان با بازی، تمرین و پیشرفت مرحله‌به‌مرحله

**LinguaPlay** محصولی مستقل برای آموزش زبان است؛ جدا از KlassYar که بر آموزش دروس مدرسه تمرکز دارد.

</div>

## ✨ امکانات

- 🧠 تمرین واژگان و گرامر با مجموعه فعالیت‌های زبانی
- 🎮 مکانیک‌های متنوع: آزمون، تطبیق، پاسخ کوتاه، جای خالی، واژه‌سازی و دسته‌بندی
- 🔎 جست‌وجو و فیلتر فعالیت‌ها بر اساس موضوع
- 📈 ذخیره پیشرفت روی دستگاه با localStorage
- 📱 رابط واکنش‌گرا و آماده بسته‌بندی Android با Capacitor
- 🔒 بدون نیاز اجباری به حساب ابری یا API آنلاین

## 🧰 فناوری‌ها

React 18 · Vite 5 · Capacitor 7 · Lucide

## 🚀 اجرا در محیط توسعه

```bash
npm install
npm run dev
```

## 🏗️ ساخت نسخه وب

```bash
npm run build
npm run preview
```

## 🤖 ساخت Android

پس از نصب Android Studio و Android SDK:

```bash
npm install
npx cap add android
npm run android:sync
cd android
./gradlew assembleDebug
```

برای ساخت APK انتشار امضاشده، راهنمای [Android Release Signing](docs/ANDROID_RELEASE_SIGNING_FA.md) را دنبال کنید. کلید امضا نباید وارد Git شود.
